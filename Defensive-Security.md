# Defensive Security 
## What Is Defensive Security?
Defensive Security = Protecting systems and detecting attacks.

## Improtant Concepts
Blue Team = defensive cybersecurity team 
Firewall = control incoming and outgoing network traffic
IPS (Intrusion Prevention System) = This blocks malicious traffic
SOC = Security Operations Center
Threat Intelligence = Information about cyber threats
Malware Analysis = Studying malicious software

## Goal of Defensive Security
- Prevent attacks
- Monitor systems
- detect threats
- respond to incidents
